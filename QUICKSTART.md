# 60-Second Judge Quick Start

### The Key Innovation in One Sentence:
> **Instead of asking whether two submissions use the same words, the system asks whether they communicate or implement the same underlying information.**

---

### Step-by-Step 60-Second Demonstration

1. **Open the Demo Dashboard**: Launch the Streamlit application.
2. **Access Sidebar**: Expand **🚀 LIVE DEMO MODE** in the sidebar.
3. **Step 1 — Load Demo Corpus**:
   - Click `[1. Load Demo Corpus]`
   - *Result:* Ingests academic papers on machine learning into the FAISS index with character spans and page numbers.
4. **Step 2 — Run Cross-Lingual Demo**:
   - Click `[2. Cross-Lingual Demo]`
   - *Result:* Compares English reference against a Hindi translation. Shows **0.0% lexical overlap** alongside **> 0.70 semantic similarity**.
5. **Step 3 — Run Document Paraphrase Demo**:
   - Click `[3. Document Paraphrase Demo]`
   - *Result:* Analyzes a reworded PDF essay. Shows the **Token Coverage %** gauge, **Risk Band**, and expandable side-by-side matches.
6. **Step 4 — Run Code AST Demo**:
   - Click `[4. Code AST Demo]`
   - *Result:* De-aliases Python code. Flags **Variable Renaming Detected** with **100% structural fidelity**.
7. **Step 5 — Run Audio Demo**:
   - Click `[5. Audio Demo]`
   - *Result:* Matches spoken ideas to the reference document with playback timestamps (`00:04 — 00:28`).

*(Alternative: Click `[▶ Run Full Demo]` to run all 5 scenarios automatically).*
